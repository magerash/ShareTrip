# Code map — where everything lives

A path plus what it is *for*. Synthesis, not a file dump: if a reader could get this from
`ls`, it is not earning its line. What earns a line is the sentence that says why the file
exists and what it knows that its neighbours do not.

**Coverage.** Every source file that ships or runs: the whole of `web/` and `tests/`, plus
the wiki tools. Not listed: the brand pack's individual PNGs (`web/assets/icons/*`, one line
covers them) and the scaffolded wiki templates under `docs/` that carry no project content
yet. Every path below was verified with `test -e`; re-verify
with `python3 tools/wiki/wiki-doctor.py`, which does the same thing on every path in this
file and is the reason nobody has to do it by hand.

---

## Ядро денег — money core

Единственное место, где происходит арифметика с деньгами. Ни одного обращения к DOM и ни
одного импорта из приложения: ядро читается и тестируется без браузера. Целые минорные
единицы и `BigInt` вместо чисел с плавающей точкой (D-001), курс как строка,
замороженная в операции (D-002), детерминированное распределение остатка (D-003).

| Path | Purpose |
|---|---|
| `web/js/money.js` (267 lines) | Разбор введённой человеком суммы («1 234,56», «1.234,56», «85000»), формат для показа, арифметика курса на `BigInt` с округлением половины вверх, `impliedRate()` — вывод фактического курса обменника из «ушло / пришло», и `allocate()` — метод наибольшего остатка с детерминированным тай-брейком. Сумма долей **всегда** равна целому; именно это ломается у конкурентов. |
| `web/js/model.js` (338 lines) | Предметная область как чистые функции над состоянием: остатки счетов, `netPositions()` («кто сколько внёс и сколько должен»), `settlementPlan()` («кто кому платит»), общая касса и `fxDrift` (D-007), режимы деления и валидация. Не знает ни про DOM, ни про базу — поэтому весь расчёт проверяется в Node. |
| `web/js/split.js` (85 lines) | Как делится чек и что считается корректной записью: режимы деления (поровну / точные суммы / доли / проценты), помощник «личная позиция на общем чеке» и валидация с человеческим текстом («Осталось распределить: X»). Отделено от `model.js` по правилу бюджета файлов. |
| `web/js/currencies.js` (56 lines) | Список валют для выпадающих полей, отсортированный под поездки из России. Курсов здесь нет и быть не может (D-004). |

**Entry points:** `node --test "tests/*.test.mjs"`

## Хранение и состояние

Поездка лежит в IndexedDB **одним документом** (D-006): для двоих это десятки килобайт,
всё помещается в память, и любой экран рисуется без ожидания курсоров. Запись происходит
сразу после мутации, без отложенного сохранения (D-008).

| Path | Purpose |
|---|---|
| `web/js/db.js` (183 lines) | Обёртка над IndexedDB: хранилища `trips`, `journal`, `meta`; экспорт и импорт полного дампа. Каждый вызов обёрнут так, чтобы отказ хранилища (инкогнито, запрет сайту) возвращал ошибку, а не ронял приложение. |
| `web/js/store.js` (324 lines) | Единственное изменяемое состояние. Все мутации проходят здесь, каждая пишет строку в журнал и немедленно сохраняет документ; экраны подписываются на изменения. Здесь же мягкая миграция старых документов — недостающие поля добавляются, ничего не удаляется. |
| `web/js/csv.js` (206 lines) | Выгрузка в CSV: разделитель `;` и BOM, потому что Excel с русской локалью иначе покажет кракозябры и склеит колонки. Четыре листа — траты, переводы, счета, расчёт. Бесплатно и в MVP: у конкурентов это за пейволлом. |

**Entry points:** вкладка «Ещё» → «CSV — всё» / «Резервная копия»

## Интерфейс

Ни одного фреймворка: состояние маленькое, экранов четыре, полная перерисовка укладывается
в миллисекунды (D-009). Вёрстка под планшет — крупные цели касания, нижняя навигация,
шторки снизу.

| Path | Purpose |
|---|---|
| `web/index.html` (38 lines) | Оболочка: мета-теги PWA, иконки, ссылка на манифест. Больше ничего — разметку строит JavaScript. |
| `web/css/app.css` (455 lines) | Токены фирменного стиля (`--navy`, `--teal`, `--sky`, `--gold`), тёмная тема по системной настройке и через `data-theme`, безопасные зоны, цели касания не меньше 44–52 px. |
| `web/js/ui.js` (275 lines) | Мини-слой над DOM: `h()` для создания элементов, `mount()` — **безопасная** вставка, которая пропускает `null` (нативный `append(null)` вставляет текст «null»), шторки с поддержкой кнопки «назад», тосты, поля, склонения и даты по-русски. |
| `web/js/app.js` (212 lines) | Оболочка приложения: загрузка последней поездки, нижняя навигация, первый запуск, регистрация service worker. |
| `web/js/views/expenses.js` (126 lines) | Лента трат: карточка итогов поездки, группировка по дням, строка траты с плательщиком и способом деления. |
| `web/js/views/expense-sheet.js` (471 lines) | Форма ввода траты — самый нагруженный экран. Всё редкое (курс, дата, название, заметка) свёрнуто, чтобы типовая трата занимала два-три касания. Здесь же несколько плательщиков, личная позиция и подстановка списания по карте при DCC (D-005). |
| `web/js/views/accounts.js` (376 lines) | Счета с остатками и переводы между ними: обменник, банкомат с комиссией, взносы в общую кассу. Показывает фактический курс, выведенный из сумм, и предлагает сделать его курсом поездки. |
| `web/js/views/settle.js` (298 lines) | «Кто кому должен»: одна строка сверху, под ней полная разбивка по каждому участнику. Никакого «упрощения долгов» (D-010). Запись расчёта — в любой валюте, с замороженным курсом. |
| `web/js/views/more.js` (366 lines) | Курсы валют, настройки поездки, участники, категории, выгрузка CSV, резервная копия и журнал изменений. |
| `web/sw.js` (63 lines) | Service worker: сеть первой, кэш запасным. Нужен только чтобы страница открывалась при перезагрузке без сети; считает приложение всё равно на устройстве. |
| `web/manifest.webmanifest` (19 lines) | Манифест PWA — иконки, цвета, `display: standalone`, чтобы приложение ставилось на домашний экран планшета. |
| `web/assets/` | Фирменные материалы из бренд-пака: логотип, символ, иконки приложения и favicon. |

**Entry points:** `python3 -m http.server 8000 --directory web`, затем `http://localhost:8000`
