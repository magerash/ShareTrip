# Glossary — ShareTrip

Terms **in the sense this project uses them**. That qualifier is the entire point: a
glossary that repeats the dictionary is dead weight, and one that records where this
project's usage *departs* from the obvious reading is the document people come back to.

Group terms into families rather than alphabetising — a reader arrives with a subject, not
a letter. Each entry: the term, any spellings and translations it travels under, the
definition, and a pointer to the file or the id that owns it.

**When to add a term.** The moment you catch yourself explaining it for the second time, or
the moment two people use the same word for different things in one conversation. Both are
cheap signals and both are usually ignored until somebody ships the wrong thing.
