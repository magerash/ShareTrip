**Путешествуем вместе. Считаем просто.**

Трекер трат для поездки вдвоём. Отвечает на один вопрос — *кто кому должен и почему* —
через несколько валют, наличные, карты и общую кассу.

Приложение написано под конкретную боль: существующие трекеры делятся на два лагеря.
Одни (Splitwise, Tricount, Settle Up) умеют «кто кому должен», но не знают, что такое счёт.
Другие (Wallet, Spendee, Дзен-мани) ведут мультивалютные счета, но не считают долг. Для
поездки вдвоём нужно и то и другое сразу — и ещё курс, который **не** берётся из интернета.

---

## Что внутри

- **Мультивалютные счета** — карты, наличные и общая касса, у каждого владелец.
- **Ручной курс, замороженный в момент операции.** Приложение никогда не ходит в сеть за
  курсом: он вводится руками и навсегда остаётся в той операции, где применён. Балансы не
  «поедут» задним числом.
- **Обменник и банкомат как первоклассные операции.** Вводите «ушло 20 000 ₽, пришло
  412 AZN» — фактический курс вычисляется сам и предлагается как курс поездки. Комиссия
  банкомата — отдельным полем.
- **Гибкое деление:** поровну, точные суммы, доли, проценты, «личная позиция на общем чеке»,
  несколько плательщиков на одном чеке.
- **Общая касса** — оба скидываются, из неё платятся общие траты, остаток делится в конце
  по взносам или поровну.
- **Прямой расчёт** без «упрощения долгов»: одна строка сверху и полная разбивка под ней.
- **Детерминированное округление.** Лишняя копейка всегда достаётся одному и тому же — метод
  наибольшего остатка, а не случайность.
- **Полный офлайн.** Всё считается на устройстве. Сеть не нужна нигде и никогда.
- **Выгрузка CSV** — бесплатно и сразу, четыре листа, открывается в Excel без плясок.

## Запуск

```bash
python3 -m http.server 8000 --directory web    # затем http://localhost:8000
```

Свежему клону не нужно **ничего**: ни `npm install`, ни сборки, ни ключей. Клиент — нативные
ES-модули, любой статический сервер их отдаёт.

> Открыть `web/index.html` двойным кликом не получится: браузер запрещает ES-модули и
> IndexedDB на схеме `file://`. Нужен http.

## Проверка

```bash
npm test          # 57 случаев: денежное ядро, модель расчёта, выгрузка
npm run smoke     # живой прогон в Chromium: 21 шаг по реальному интерфейсу
npm run wiki      # ссылки и регламент вики
```

Единственная зависимость — Playwright, и только для `smoke`. Само приложение не зависит ни
от чего.

## Прежде чем менять код

Прочитайте [docs/README.md](docs/README.md) — там регламент, и
[AGENTS.md](AGENTS.md) — там правила репозитория и несущие факты, каждый из которых уже
однажды был нарушен. Коротко самое важное:

1. **Деньги — целые.** Ни одного числа с плавающей точкой в хранимых данных.
2. **Курс заморожен.** Пересчитывать `amountHome` задним числом нельзя.
3. **Инвариант — `Σ final === 0`**, а не «сумма позиций равна остатку кассы»: при
   замороженных курсах второе не выполняется, и это нормально (D-007).
4. **Условных потомков вставлять только через `mount()`** — нативный `append(null)` рисует
   на экране слово «null».

## Чего здесь нет и не будет

Автоматического «упрощения долгов» (для двоих бессмысленно и всех путает), банковской
синхронизации, чата, бюджетов-конвертов и обязательной регистрации. Функция попадает в
приложение, только если закрывает конкретный сценарий, а не потому что «есть у Splitwise».
